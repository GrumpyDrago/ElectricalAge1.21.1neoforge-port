## NOT Chip

<ItemImage id="eln:not_chip" />

Inverts the input signal.  
Outputs a voltage representing the  
opposite logic-level to its input.  

## AND Chip

<ItemImage id="eln:and_chip" />

Implements logical conjunction.  
A 1 (high) output results only if all of  
the three inputs to the AND gate are 1 (high).  

## NAND Chip

<ItemImage id="eln:nand_chip" />

Its output is complement (inverted)  
to that of the AND gate.  

## OR Chip

<ItemImage id="eln:or_chip" />

Implements logical disjunction.  
A 1 (high) output results if at least  
one input to the gate is 1 (high).  

## NOR Chip

<ItemImage id="eln:nor_chip" />

Its output is complement (inverted)  
to that of the OR gate.  

## XOR Chip

<ItemImage id="eln:xor_chip" />

Implements an exclusive or.  
An output of 1 (high) results if one or  
all three inputs to the gate are 1 (high).  

## XNOR Chip

<ItemImage id="eln:xnor_chip" />

Its output is complement (inverted)  
to that of the XOR gate.  

## PAL Chip

<ItemImage id="eln:pal_chip" />

A Programmable Array Logic (PAL) is a programmable  
logic device semiconductors used to  implement any logic  
function in only one digital circuit. The function is  
stateless, which means that no intermediate state is saved.  

## Schmitt Trigger Chip

<ItemImage id="eln:schmitt_trigger_chip" />

If the input voltage is lower than 10V, the  
output is 0 (low), if the input is bigger or  
equal to 30V, the output will be 1 (high). For  
all voltages in between, the output does not change.  

## D Flip Flop Chip

<ItemImage id="eln:d_flip_flop_chip" />

The D flip-flop captures the value  
of the D-input at a rising edge  
portion of the clock cycle.  

## Oscillator Chip

<ItemImage id="eln:oscillator_chip" />

Outputs a rectangular signal which's frequency  
depends to the input voltage. The higher the  
input voltage - the higher the frequency.  

## JK Flip Flop Chip

<ItemImage id="eln:jk_flip_flop_chip" />

If the input J is 1 (high) and K is 0 (low)  
during a clock pulse, the output becomes 1 (high).  
If J is 0 (low) and K is 1 (high) during the pulse,  
the output becomes 0 (low). If both inputs are 0 (low)  
during the clock pulse, the state is maintained. If both  
inputs are 1 (high) the input is toggled if a rising edge  
was detected at the clock input.  

## OpAmp

<ItemImage id="eln:opamp" />

Operational Amplifier - DC coupled  
high-gain voltage amplifier with  
differential input. Can be used to  
compare voltages or as configurable amplifier.  

## PID Regulator

<ItemImage id="eln:pid_regulator" />

Proportional–integral–derivative controller. A PID  
controller continuously calculates an error value as  
the difference between a desired setpoint and a measured  
process variable and applies a correction based on  
proportional, integral, and derivative terms.
