# Creative

Parts for creative mode and testing.

## Ground Cable

<ItemImage id="eln:ground_cable" />

Provides a zero volt reference.  
Can be used to set a point of an  
electrical network to 0V potential.  
For example to ground negative battery contacts.  
Internal resistance: 12.5mΩ  

## Voltage Source

<ItemImage id="eln:electrical_source" />

Provides an ideal voltage source  
without energy or power limitation.  
Internal resistance: 12.5mΩ  
Creative block.  

## Signal Source

<ItemImage id="eln:signal_source" />

Provides an ideal voltage source  
without energy or power limitation.  
Internal resistance: 12.5mΩ  
Creative block.  

## Current Source

<ItemImage id="eln:current_source" />
